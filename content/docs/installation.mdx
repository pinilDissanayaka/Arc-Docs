## Install Arc Framework

---


### 🧩 Install Arc

Arc is designed for **AI Agent Orchestration**, **Multi-Agent Workflows**, and **Reinforcement Learning** in one cohesive framework.

To install the Arc package:

#### pip

```bash
pip install --pre -U arc-framework
```

### Graph visualization

```bash
pip install --pre -U graphviz
```


### 🧠 Verify Installation
Once installed, verify Arc is working correctly:

```bash
python -m arc --version
```

Expected output:
```bash
Arc Framework v1.0.0
```
