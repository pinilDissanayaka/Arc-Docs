### 🧩 Install Arc-Flow

Arc-Flow is designed for **AI Agent Orchestration**, **Multi-Agent Workflows**, and **Reinforcement Learning** in one cohesive framework.

To install the Arc-Flow package:

#### pip

```bash
pip install arc-flow
```

### Graph visualization

```bash
pip install --pre -U graphviz
```


### 🧠 Verify Installation
Once installed, verify Arc-Flow is working correctly:

```bash
python -m arc --version
```

Expected output:
```bash
Arc Framework v1.0.0
```
