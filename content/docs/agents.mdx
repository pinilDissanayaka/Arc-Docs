## Introduction

Advanced agent patterns enable sophisticated reasoning capabilities beyond standard ReAct agents. These patterns implement proven techniques from AI research to improve output quality, consistency, and reliability.

### Pattern Overview

| Pattern | Purpose | Complexity | Quality | Speed | Best For |
|---------|---------|-----------|---------|-------|----------|
| Self-Consistency | Multiple solutions, select best | Medium | High | Slow | Math, reasoning |
| Reflexion | Iterative refinement | High | Highest | Slowest | Complex analysis |
| Reasoning Duo | Separate thinking/communication | Medium | High | Medium | Decisions |
| Agent Judge | Evaluate outputs | Low | High | Fast | Quality assurance |

### When to Use Advanced Patterns

**Use when:**
- Quality is more important than speed
- Tasks require deep reasoning
- Need high confidence in answers
- Critical decisions or analysis
- Willing to trade latency for accuracy

**Avoid when:**
- Simple queries
- Real-time requirements
- Cost-sensitive applications
- Basic information retrieval

## Self-Consistency Pattern

Generate multiple independent reasoning paths and select the most consistent answer through majority voting.

### Core Concept

```
Problem → [Agent 1] → Solution A
       → [Agent 2] → Solution B
       → [Agent 3] → Solution C
       → [Agent 4] → Solution D
       → [Agent 5] → Solution E

Majority Vote: A, B, A, A, D → Answer: A (most common)
```

### Basic Usage

```python
from arc.agents import create_agent
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini")

# Create self-consistency agent
sc_agent = create_agent(
    pattern="self-consistency",
    llm=llm,
    tools=[],
    num_samples=5,  # Generate 5 independent solutions
    temperature=0.7  # Higher temperature for diversity
)

# Use for questions with multiple solution paths
result = sc_agent.invoke({
    "messages": [("user", "If I have 3 apples and buy 2 more, then give away 1, how many do I have?")]
})

print(result["messages"][-1].content)
# Output: "4 apples" (with high confidence)
```

### How It Works

1. **Generate Multiple Solutions**: Run the same prompt N times with sampling
2. **Diversity**: Use temperature > 0 for varied reasoning paths
3. **Majority Voting**: Count most common answer
4. **Aggregation**: LLM synthesizes final response explaining consensus

### Advanced Configuration

```python
sc_agent = create_agent(
    pattern="self-consistency",
    llm=llm,
    tools=[calculator, search],
    num_samples=7,  # More samples = higher confidence
    temperature=0.7,
    majority_voting_prompt="""
    Analyze these {num_samples} solutions:

    {solutions}

    Task:
    1. Check mathematical/logical correctness of each
    2. Identify the most common answer
    3. Explain why that answer is correct
    4. Note any edge cases or considerations
    5. Provide the final answer with confidence level

    Respond in JSON:
    {{
      "answer": "...",
      "confidence": 0.0-1.0,
      "reasoning": "...",
      "edge_cases": [...]
    }}
    """
)
```

```python
# Adaptive sampling
def adaptive_consistency(problem, min_samples=3, max_samples=10, confidence_threshold=0.8):
    """Adaptive self-consistency - generate samples until confident."""

    samples = []
    for i in range(max_samples):
        result = agent.invoke({"messages": [("user", problem)]})
        samples.append(result["messages"][-1].content)

        if i >= min_samples - 1:
            # Check if we have strong consensus
            from collections import Counter
            counts = Counter(samples)
            most_common_count = counts.most_common(1)[0][1]
            confidence = most_common_count / len(samples)

            if confidence >= confidence_threshold:
                print(f"Reached confidence threshold with {i+1} samples")
                break

    return samples
```

## Reflexion Pattern

Iteratively refine outputs through self-reflection, evaluation, and continuous improvement.

### Core Concept

```
Loop:
  1. Act: Generate initial response
  2. Evaluate: Score quality (0-10)
  3. Reflect: Identify what to improve
  4. Refine: Generate improved response
Until: Quality threshold met or max iterations
```

### Basic Usage

```python
from arc.agents import create_agent

# Create reflexion agent
reflexion_agent = create_agent(
    pattern="reflexion",
    llm=llm,
    tools=[search_tool],
    max_loops=3,  # Maximum reflection iterations
    memory_capacity=100  # Memory for past reflections
)

# Use for complex reasoning
result = reflexion_agent.invoke({
    "messages": [("user", "Explain the implications of quantum computing on current encryption")]
})

print(result["messages"][-1].content)

# Process:
# Loop 1: Initial answer (score: 6/10)
#   Reflection: "Missing specific examples, too general"
# Loop 2: Improved answer (score: 8/10)
#   Reflection: "Better examples, but need more technical depth"
# Loop 3: Final answer (score: 9/10)
#   Quality threshold met
```

### How It Works

1. **Act**: Agent generates initial response
2. **Evaluate**: System scores response quality (0-10)
3. **Reflect**: Agent analyzes what's missing or wrong
4. **Refine**: Agent generates improved response incorporating reflections
5. **Repeat**: Continue until quality threshold or max loops

### Advanced Configuration


### Memory System

Reflexion maintains short-term and long-term memory:

```python
# Short-term memory: Current task reflections
# - Stored for current invocation only
# - Includes all reflection cycles
# - Used to avoid repeating mistakes

# Long-term memory: Past successful approaches
# - Stored across invocations
# - Learns from multiple tasks
# - Applied to similar future problems

# Example: Memory in action

    "messages": [("user", "Explain machine learning")]
})

# Later, agent remembers what worked

    "messages": [("user", "Explain deep learning")]
})
# Agent applies lessons learned from ML explanation
```

### Monitoring Progress

```python
def monitor_reflexion(agent, query, verbose=True):
    """Monitor reflexion progress."""

    results = []

    # Override agent's evaluation to track progress
    original_evaluate = agent._evaluate

    def tracked_evaluate(response):
        score = original_evaluate(response)
        results.append({
            "iteration": len(results) + 1,
            "score": score,
            "response_length": len(response)
        })

        if verbose:
            print(f"Iteration {len(results)}: Score = {score:.1f}/10")

        return score

    agent._evaluate = tracked_evaluate

    # Run agent
    result = agent.invoke({"messages": [("user", query)]})

    # Restore original evaluate
    agent._evaluate = original_evaluate

    # Plot progress
    import matplotlib.pyplot as plt

    iterations = [r["iteration"] for r in results]
    scores = [r["score"] for r in results]

    plt.plot(iterations, scores, marker='o')
    plt.xlabel("Iteration")
    plt.ylabel("Quality Score")
    plt.title("Reflexion Progress")
    plt.grid(True)
    plt.savefig("reflexion_progress.png")

    return result, results

# Use monitoring
result, progress = monitor_reflexion(reflexion_agent, "Explain quantum entanglement")
```

## Reasoning Duo Pattern

Two agents working together: one for deep reasoning, one for clear communication.

### Core Concept

```
Query
  ↓
┌─────────────────┐
│ Reasoning Agent │ → Deep analysis, thorough thinking
│  (Think deeply) │    Consider all angles
└────────┬────────┘    No communication constraints
         │
    [Raw reasoning]
         │
         ↓
┌─────────────────┐
│   Main Agent    │ → Synthesize reasoning into
│ (Communicate)   │    clear, actionable response
└─────────────────┘
```

### Basic Usage

```python
from arc.agents import create_agent

# Create reasoning duo
duo_agent = create_agent(
    pattern="reasoning-duo",
    llm=llm,
    tools=[search, calculator],
    max_loops=1  # Typically single pass
)

# Use for complex decisions
result = duo_agent.invoke({
    "messages": [("user", "Should our company adopt microservices architecture?")]
})

print(result["messages"][-1].content)

# Process:
# 1. Reasoning Agent analyzes deeply:
#    - Technical considerations (scalability, complexity)
#    - Business implications (cost, time to market)
#    - Risk factors (operational overhead, team skills)
#    - Trade-offs (flexibility vs simplicity)
#
# 2. Main Agent synthesizes into clear recommendation:
#    "Based on analysis, I recommend [YES/NO] because [reasons].
#     Key considerations: [1, 2, 3].
#     Potential risks: [X, Y, Z].
#     Next steps: [a, b, c]."
```

### How It Works

1. **Reasoning Agent**:
   - Thinks deeply without communication constraints
   - Explores all angles and implications
   - Considers trade-offs and risks
   - Generates thorough analysis

2. **Main Agent**:
   - Receives reasoning agent's analysis
   - Synthesizes into clear, actionable response
   - Structures for target audience
   - Provides recommendations and next steps

### Advanced Configuration

## Agent Judge Pattern

Evaluate outputs from agents against specific criteria and provide scored feedback.

### Core Concept

```
Agent Output → Judge Agent → Score + Feedback
```

### Basic Usage

```python
from arc.agents import create_agent

# Create judge
judge = create_agent(
    pattern="agent-judge",
    llm=llm,
    evaluation_criteria=[
        "Accuracy",
        "Completeness",
        "Clarity",
        "Relevance",
        "Actionability"
    ],
    return_score=True
)

# Evaluate an agent's output
question = "What is photosynthesis?"
answer = "Photosynthesis is how plants make food using sunlight."

result = judge.invoke({
    "messages": [
        ("user", question),
        ("assistant", answer)
    ]
})

evaluation = result["evaluation"]
score = result["score"]  # 0-10

print(f"Score: {score}/10")
print(f"Feedback: {evaluation}")

# Output:
# Score: 6/10
# Feedback: The answer is correct but incomplete. It should explain:
# - The role of chlorophyll
# - Inputs (CO2, water, light)
# - Outputs (glucose, oxygen)
# - The chemical equation
```

### How It Works

1. **Receive Input**: Question and answer to evaluate
2. **Apply Criteria**: Score against each criterion
3. **Calculate Score**: Aggregate individual criterion scores
4. **Generate Feedback**: Explain score and suggest improvements

### Advanced Configuration

```python
# Weighted criteria
judge = create_agent(
    pattern="agent-judge",
    llm=llm,
    evaluation_criteria={
        "Technical Accuracy": 0.4,  # 40% weight

        "Completeness": 0.2,  # 20% weight

    },
    return_score=True,
    score_range=(0, 100),  # Custom range
    evaluation_prompt="""
    Evaluate this response carefully:

    Question: {question}
    Answer: {answer}

    Criteria and weights:
    {criteria}

    For each criterion:
    1. Assign score based on weight
    2. Explain reasoning
    3. Suggest specific improvements

    Final format:
    {{
      "scores": {{criterion: score}},
      "overall_score": X,
      "feedback": "...",
      "improvements": [...]
    }}
    """
)
```

### Example: Agent A/B Testing

```python
# Create two agents with different approaches
agent_a = factory.create_react_agent("agent_a", [tools], prompt="Approach A")
agent_b = factory.create_react_agent("agent_b", [tools], prompt="Approach B")

# Create judge
judge = create_agent(
    pattern="agent-judge",
    llm=llm,
    evaluation_criteria=[
        "Accuracy",
        "Completeness",
        "Efficiency",
        "User satisfaction"

    return_score=True
)

# Test queries
test_queries = [
    "Explain machine learning",
    "Calculate ROI for project",
    "Summarize research paper",
    # ... more queries
]

scores_a = []
scores_b = []

for query in test_queries:
    # Agent A
    result_a = agent_a.invoke({"messages": [("user", query)]})
    eval_a = judge.invoke({
        "messages": [
            ("user", query),
            ("assistant", result_a["messages"][-1].content)
        ]
    })
    scores_a.append(eval_a["score"])

    # Agent B
    result_b = agent_b.invoke({"messages": [("user", query)]})
    eval_b = judge.invoke({
        "messages": [
            ("user", query),
            ("assistant", result_b["messages"][-1].content)
        ]

    scores_b.append(eval_b["score"])

# Compare
avg_a = sum(scores_a) / len(scores_a)
avg_b = sum(scores_b) / len(scores_b)

print(f"Agent A average score: {avg_a:.2f}/10")
print(f"Agent B average score: {avg_b:.2f}/10")
print(f"Winner: Agent {'A' if avg_a > avg_b else 'B'}")

# Statistical significance test
from scipy import stats
t_stat, p_value = stats.ttest_ind(scores_a, scores_b)

print(f"Statistically significant: {p_value < 0.05}")
```

```python
def batch_evaluate(judge, test_cases):
    """Evaluate multiple test cases."""

    results = []

    for question, answer in test_cases:
        eval_result = judge.invoke({
            "messages": [("user", question), ("assistant", answer)]
        })

        results.append({
            "question": question,
            "answer": answer,
            "score": eval_result["score"],
            "feedback": eval_result["evaluation"]

# Find low-scoring answers

print(f"\nLow-scoring answers ({len(low_scores)}):")
for r in low_scores:
    print(f"  Q: {r['question']}")
    print(f"  Score: {r['score']}/10")
    print(f"  Feedback: {r['feedback'][:100]}...")
```

## Combining Patterns

Advanced patterns can be combined for even more sophisticated reasoning.

### Reflexion + Self-Consistency

Generate multiple solutions with iterative refinement.

```python
def reflexion_with_consistency(query: str, llm, tools):
    """Combine reflexion and self-consistency."""

    # Step 1: Use reflexion to generate refined answer
    reflexion_agent = create_agent(
        pattern="reflexion",
        llm=llm,
        tools=tools,
        max_loops=2
    )

    refined = reflexion_agent.invoke({
        "messages": [("user", query)]
    })

    # Step 2: Use self-consistency to verify
    sc_agent = create_agent(
        pattern="self-consistency",
        llm=llm,
        tools=tools,
        num_samples=5
    )

    validated = sc_agent.invoke({
        "messages": [("user", query)]
    })

    # Step 3: Compare and choose
    judge = create_agent(pattern="agent-judge", llm=llm)

    comparison = judge.invoke({
        "messages": [
            ("user", f"Question: {query}"),
            ("assistant", f"Reflexion answer: {refined['messages'][-1].content}"),
            ("assistant", f"Consistency answer: {validated['messages'][-1].content}")
        ]
    })

    # Return highest scoring answer
    if comparison["score"] >= 8:
        return validated  # Self-consistency wins
    else:
        return refined  # Reflexion wins

# Use combined approach
result = reflexion_with_consistency(
    "What are the implications of quantum computing for cryptography?",
    llm,
    tools
)
```

```python
def strategic_decision_with_review(query: str, llm):
    """Strategic decision with quality review."""

    # Step 1: Deep reasoning with duo
    duo = create_agent(pattern="reasoning-duo", llm=llm)
    decision = duo.invoke({"messages": [("user", query)]})

    # Step 2: Evaluate decision quality
    judge = create_agent(
        pattern="agent-judge",
        llm=llm,
        evaluation_criteria=[
            "Strategic alignment",
            "Risk assessment",
            "Feasibility",
            "Expected impact",
            "Clarity of recommendation"
        ]
    )

    evaluation = judge.invoke({
        "messages": decision["messages"]
    })

    # Step 3: Refine if score low
    if evaluation["score"] < 7:
        # Use reflexion to improve
        reflexion = create_agent(pattern="reflexion", llm=llm, max_loops=2)

        feedback_prompt = f"""
        {query}

        Previous response:
        {decision['messages'][-1].content}

        Feedback (score: {evaluation['score']}/10):
        {evaluation['evaluation']}

        Improve the response based on this feedback.
        """

        improved = reflexion.invoke({"messages": [("user", feedback_prompt)]})
        return improved

    return decision
```

### Self-Consistency + Judge (Quality Gating)

Only accept answers meeting quality threshold.

```python
def quality_gated_consistency(query: str, llm, tools, threshold=8.0):
    """Self-consistency with quality gating."""

    max_attempts = 3

    for attempt in range(max_attempts):
        # Generate answer with self-consistency
        sc_agent = create_agent(
            pattern="self-consistency",
            llm=llm,
            tools=tools,
            num_samples=5 + attempt * 2  # Increase samples each attempt
        )

        result = sc_agent.invoke({"messages": [("user", query)]})

        # Evaluate quality
        judge = create_agent(pattern="agent-judge", llm=llm)
        evaluation = judge.invoke({"messages": result["messages"]})

        print(f"Attempt {attempt + 1}: Score = {evaluation['score']:.1f}/10")

        if evaluation["score"] >= threshold:
            print("Quality threshold met!")
            return result

    print("Max attempts reached, returning best effort")
    return result

# Use quality-gated approach
result = quality_gated_consistency(
    "Explain the proof of Fermat's Last Theorem",
    llm,
    tools,
    threshold=8.5
)
```

## Pattern Selection Guide

### Decision Matrix

| Task Type | Recommended Pattern | Why |
|-----------|-------------------|-----|
| Mathematical reasoning | Self-Consistency | Multiple solution paths, clear right/wrong |
| Complex essay/report | Reflexion | Iterative refinement improves quality |
| Strategic decision | Reasoning Duo | Separate deep analysis from communication |
| Quality assurance | Agent Judge | Systematic evaluation against criteria |
| Research paper | Reflexion + Judge | Generate quality content with validation |
| Code generation | Self-Consistency + Judge | Multiple approaches, verify correctness |
| High-stakes analysis | Reasoning Duo + Reflexion | Deep thinking + continuous improvement |

### Performance vs Quality Trade-off

```
Quality
  ^
  |                    ● Reflexion + Judge
  |                  ● Reasoning Duo + Reflexion
  |                ● Heavy reasoning patterns
  |              ● Reasoning Duo
  |            ● Reflexion
  |          ● Self-Consistency
  |        ● Basic Reflexion
  |      ● Self-Consistency (3 samples)
  |    ● Standard ReAct
  |  ● Simple prompt
  |___________________________________> Speed
```

### Pattern Router

```python
class AdvancedPatternRouter:
    """Route to appropriate advanced pattern based on task."""

    def __init__(self, llm):
        self.llm = llm
        self.agents = {
            "self_consistency": create_agent("self-consistency", llm),
            "reflexion": create_agent("reflexion", llm),
            "reasoning_duo": create_agent("reasoning-duo", llm),
            "standard": factory.create_react_agent("standard", [])
        }

    def route(self, task: str) -> str:
        """Select appropriate pattern."""

        task_lower = task.lower()

        # Math/reasoning → Self-Consistency
        if any(word in task_lower for word in ["calculate", "solve", "prove", "how many"]):
            return "self_consistency"

        # Analysis/writing → Reflexion
        elif any(word in task_lower for word in ["explain", "analyze", "write", "essay"]):
            return "reflexion"

        # Decision/strategy → Reasoning Duo
        elif any(word in task_lower for word in ["should", "recommend", "evaluate", "decide"]):
            return "reasoning_duo"

        # Default → Standard
        else:
            return "standard"

    def execute(self, task: str):
        """Route and execute."""
        pattern = self.route(task)
        agent = self.agents[pattern]

        print(f"Using pattern: {pattern}")

        return agent.invoke({"messages": [("user", task)]})

# Use router
router = AdvancedPatternRouter(llm)
result = router.execute("Calculate compound interest on $1000 at 5% for 10 years")
```
