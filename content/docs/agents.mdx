## Introduction

The Arc provides a comprehensive suite of agent types and patterns for building sophisticated AI applications. Agents in Arc are autonomous entities that can reason, act, and learn through interaction with tools and environments.

### What is an Agent?

An **agent** in Arc is an autonomous entity that:

1. **Receives** tasks or goals from users
2. **Reasons** about how to accomplish them using an LLM
3. **Acts** by selecting and executing appropriate tools
4. **Observes** the results of actions
5. **Iterates** until the goal is achieved or constraints are met

### Core Components

Every Arc agent consists of:

- **LLM (Language Model)**: The "brain" for reasoning and decision-making
- **Tools**: Functions the agent can execute to interact with the world
- **State**: Current context, conversation history, and metadata
- **Execution Graph**: Internal workflow managed by LangGraph
- **Memory** (optional): For learning and context retention across interactions

## Agent Architecture

### Base Architecture

All agents inherit from `BaseAgent`, providing a consistent interface:

```python
from arc.core.base import BaseAgent

class BaseAgent(ABC):
    """Abstract base class for all agents."""

    def __init__(
        self,
        name: str,                           # Unique identifier
        llm: BaseChatModel,                  # Language model
        tools: Optional[Sequence[BaseTool]], # Available tools
        prompt: Optional[str],               # System prompt
        description: str = ""                # Human-readable description
    ):
        self.name = name
        self.llm = llm
        self.tools = list(tools) if tools else []
        self.prompt = prompt
        self.description = description

    @abstractmethod
    def invoke(self, state: Dict[str, Any]) -> Dict[str, Any]:
        """Synchronous execution."""
        pass

    @abstractmethod
    async def ainvoke(self, state: Dict[str, Any]) -> Dict[str, Any]:
        """Asynchronous execution."""
        pass
```

## Core Agent Types

### 1. ReactAgent

**The fundamental agent implementing the ReAct (Reasoning + Acting) pattern.**

#### Overview

ReactAgent iteratively reasons about tasks and uses tools to accomplish them. It follows a simple but powerful loop:

```
Reasoning → Action → Observation → Reasoning → ...
```

#### Implementation

**Location**: `arc/agents/agent_factory.py:28-235`

```python
from arc.agents import AgentFactory, ReactAgent
from langchain_openai import ChatOpenAI
from langchain_core.tools import tool

# Define tools
@tool
def search_web(query: str) -> str:
    """Search the web for information."""
    return f"Search results for: {query}"

@tool
def calculator(expression: str) -> str:
    """Evaluate mathematical expressions."""
    return str(eval(expression))

# Create LLM
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)

# Create agent factory
factory = AgentFactory(default_llm=llm)

# Create ReactAgent
agent = factory.create_react_agent(
    name="research_agent",
    tools=[search_web, calculator],
    prompt="""
    You are a helpful research assistant.

    When given a task:
    1. Understand what the user needs
    2. Select appropriate tools
    3. Execute tools to gather information
    4. Synthesize results into a clear response

    Always use tools when you need external information.
    """,
    description="Research agent with search and calculation capabilities",
    enable_caching=True,
    cache_type="semantic"
)

# Use the agent
result = agent.invoke({
    "messages": [("user", "What is 25 * 47 and search for information about Python")]
})

response = result["messages"][-1].content
print(response)
```

#### Features

- **Tool Calling**: Automatic tool selection and execution
- **State Management**: Maintains conversation history
- **Caching**: Optional LLM response caching for performance
- **RL Support**: Can integrate with RL for intelligent tool selection
- **Error Handling**: Robust error handling with fallbacks

#### Configuration Options

```python
agent = factory.create_react_agent(
    name="agent_name",              # Required: Unique identifier
    llm=llm,                        # Optional: Uses default if not provided
    tools=[tool1, tool2],           # Optional: List of tools
    prompt="System prompt...",      # Optional: Agent personality/instructions
    description="Agent description", # Optional: Human-readable description

    # Performance
    enable_caching=True,            # Enable LLM response caching
    cache_type="exact",             # Cache type: "exact" or "semantic"

    # Reinforcement Learning
    rl_enabled=False,               # Enable RL-based tool selection
    rl_manager=None,                # RLManager instance
    reward_calculator=None          # RewardCalculator instance
)
```

#### When to Use

- **General-purpose tasks**: Most common use case
- **Tool-based workflows**: When you need tool calling
- **Simple reasoning**: Straightforward problem-solving
- **Quick responses**: When you need fast, direct answers

#### Execution Flow

```
User Query
    ↓
[ReactAgent]
    ↓
LLM Reasoning: "I should search for information"
    ↓
Action: Call search_web(query="Python")
    ↓
Tool Execution: Returns search results
    ↓
Observation: Agent receives results
    ↓
LLM Reasoning: "Good! Now I have the information"
    ↓
Final Response: Synthesized answer
```

### 2. SelfConsistencyAgent

**Agent that generates multiple independent responses and aggregates them for improved reliability.**

#### Overview

Based on the research paper "Self-Consistency Improves Chain of Thought Reasoning in Language Models" (Wang et al., 2022), this agent improves accuracy by:

1. Generating N independent responses to the same query
2. Analyzing consistency across responses
3. Using majority voting to determine the best answer
4. Providing a synthesized final response

**Location**: `arc/agents/self_consistency_agent.py:127-389`

#### Implementation

```python
from arc.agents.self_consistency_agent import SelfConsistencyAgent
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0.8)

agent = SelfConsistencyAgent(
    name="consistent_math_agent",
    llm=llm,
    tools=[calculator],
    num_samples=5,  # Generate 5 independent responses
    prompt="""
    You are a mathematical reasoning agent.
    Think through problems step-by-step.
    Show your work and arrive at a clear answer.
    """,
    description="Math agent with self-consistency"
)

# Use the agent
result = agent.invoke({
    "messages": [("user", "What is the 40th prime number?")]
})

print(result["messages"][-1].content)  # Final aggregated answer
print(result["responses"])             # All individual responses
```

#### Architecture

```
                    User Query
                         ↓
              [SelfConsistencyAgent]
                         ↓
        ┌────────────────┼────────────────┐
        ↓                ↓                ↓
   Reasoner 1       Reasoner 2       Reasoner N
   (ReactAgent)     (ReactAgent)     (ReactAgent)
        ↓                ↓                ↓
   Response 1       Response 2       Response N
        └────────────────┼────────────────┘
                         ↓
              [Aggregation Agent]
             (Majority Voting LLM)
                         ↓
                Final Synthesized
                    Response
```

#### Features

- **Concurrent Execution**: Generates responses in parallel using ThreadPoolExecutor
- **Majority Voting**: AI-powered aggregation using specialized prompt
- **Evaluation Mode**: Can validate responses against known answers
- **Batch Processing**: Process multiple queries efficiently

#### Configuration

```python
agent = SelfConsistencyAgent(
    name="agent_name",
    llm=llm,
    tools=[tool1, tool2],

    # Self-consistency specific
    num_samples=5,                    # Number of independent responses
    majority_voting_prompt=None,      # Custom aggregation prompt
    eval_mode=False,                  # Enable answer validation

    # Standard options
    prompt="System prompt...",
    description="Agent description",

    # RL support
    rl_enabled=False,
    rl_manager=None,
    reward_calculator=None
)
```

#### When to Use

- **Critical decisions**: When accuracy is paramount
- **Mathematical reasoning**: Complex calculations or logical problems
- **Ambiguous queries**: Questions with multiple valid interpretations
- **High-stakes tasks**: Where errors are costly
- **Verification needed**: When you want multiple perspectives

#### Example: Mathematical Problem

```python
# Create agent
agent = SelfConsistencyAgent(
    name="math_solver",
    llm=llm,
    tools=[calculator],
    num_samples=7,
    prompt="Solve mathematical problems step-by-step."
)

# Complex problem
result = agent.invoke({
    "messages": [("user",
        "If a train travels at 60 mph for 2.5 hours, "
        "then at 80 mph for 1.5 hours, what is the "

# Agent generates 7 independent solutions
# Aggregates them via majority voting
# Returns the most consistent answer

```

### 3. ReflexionAgent

**Self-improving agent that learns from evaluations and reflections.**

#### Overview

Based on the Reflexion framework, this agent improves through a cycle of:

1. **Acting**: Generate initial response
2. **Evaluating**: Critically assess the response quality
3. **Reflecting**: Generate insights about what worked and what didn't
4. **Refining**: Use reflections to improve the response

**Location**: `arc/agents/reflexion_agent.py:262-641`

#### Implementation

```python
from arc.agents.reflexion_agent import ReflexionAgent
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)

agent = ReflexionAgent(
    name="improving_writer",
    llm=llm,
    tools=[search_web, analyze_text],
    max_loops=3,              # Iterate up to 3 times
    memory_capacity=100,      # Store up to 100 memories
    prompt="""
    You are a professional writer who learns from feedback.
    Always strive to improve your responses based on evaluation.
    """,
    description="Self-improving writing agent"
)

# Use the agent
result = agent.invoke({
    "messages": [("user", "Write a comprehensive guide to quantum computing")]
})

print(result["messages"][-1].content)  # Best response
print(result["best_score"])            # Quality score (0-1)
print(result["iterations"])            # All iteration details
```

#### Architecture

```
                    User Query
                         ↓
                [ReflexionAgent]
                         ↓
            ┌────────────┴────────────┐
            ↓                         ↓
       [Actor Agent]             [Memory System]
    (Generates responses)       (Stores reflections)
            ↓                         ↑
       Response 1                     │
            ↓                         │
      [Evaluator Agent]               │
    (Scores: 0.6/1.0)                 │
            ↓                         │
      [Reflector Agent]               │
   (Generates insights) ──────────────┘
            ↓
     Refined Response
            ↓
      [Evaluator Agent]
    (Scores: 0.8/1.0)
            ↓
   Continue or Return Best
```

### 4. ReasoningDuoAgent

**Collaborative two-agent system: one for reasoning, one for answering.**

#### Overview

This agent uses a divide-and-conquer approach with two specialized sub-agents:

1. **Reasoning Agent**: Analyzes problems and provides detailed reasoning
2. **Main Agent**: Synthesizes reasoning into clear final answers

**Location**: `arc/agents/reasoning_duo_agent.py:64-235`

#### Implementation

```python
from arc.agents.reasoning_duo_agent import ReasoningDuoAgent
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)

agent = ReasoningDuoAgent(
    name="duo_assistant",
    llm=llm,
    tools=[search_web, calculator],
    max_loops=1,  # Number of reasoning cycles
    prompt="""
    You are a helpful assistant that provides well-reasoned answers.
    Synthesize information clearly and concisely.
    """,
    description="Collaborative reasoning agent"
)

# Use the agent
result = agent.invoke({
    "messages": [("user", "Explain how neural networks learn")]
})

print(result["messages"][-1].content)  # Final answer
print(result["conversation"])          # Full reasoning dialogue
```

#### Architecture

```
                    User Query
                         ↓
              [ReasoningDuoAgent]
                         ↓
                         ↓
              ┌──────────┴──────────┐
              ↓                     ↓
     [Reasoning Agent]        [Main Agent]
    "Let me analyze..."      (Waits for reasoning)
              ↓
    Detailed reasoning
    and analysis
              ↓                     ↓
              └──────────→    Synthesizes into
                            clear final answer
```

#### Features

- **Separated Concerns**: Reasoning and response generation separated
- **Explicit Reasoning**: Detailed analysis before answering
- **Tool Access**: Main agent can use tools based on reasoning
- **Multi-loop**: Can iterate reasoning-response cycles

#### Configuration

```python
agent = ReasoningDuoAgent(
    name="agent_name",
    llm=llm,
    tools=[tool1, tool2],  # Available to main agent

    # Reasoning duo specific
    max_loops=1,           # Reasoning-response cycles

    # Standard options
    prompt="System prompt for main agent...",
    description="Agent description",

    # RL support (for main agent)
    rl_enabled=False,
    rl_manager=None,
    reward_calculator=None
)
```

#### When to Use

- **Complex explanations**: Multi-step reasoning required
- **Educational content**: When showing reasoning is valuable
- **Decision support**: When process matters as much as conclusion
- **Transparent AI**: When users need to see the thinking process

#### Example: Complex Question

```python
agent = ReasoningDuoAgent(
    name="science_explainer",
    llm=llm,
    tools=[search_web],
    max_loops=2  # Two reasoning cycles
)

result = agent.invoke({
    "messages": [("user",
        "How do vaccines work and why are booster shots needed?"
    )]
})

# Reasoning Agent provides detailed analysis
# Main Agent synthesizes into clear explanation
```

### 5. Agent Routing and Handoff

**Dynamic agent selection and task delegation.**

#### AgentRouter

Routes tasks to the most appropriate agent from a pool.

**Location**: `arc/agents/agent_router.py:19-275`

```python
from arc.agents.agent_router import AgentRouter
from arc.agents import ReactAgent
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini")

    name="security_expert",
    llm=llm,
    tools=[check_security, scan_vulnerabilities],
    prompt="You are a cybersecurity expert.",
    description="Handles security-related tasks"
)

data_agent = ReactAgent(
    name="data_analyst",
    llm=llm,
    tools=[analyze_data, visualize],
    prompt="You are a data analysis expert.",
    description="Handles data analysis tasks"
)

# Create router
router = AgentRouter(
    name="task_router",
    agents=[security_agent, data_agent],
    llm=llm,  # For routing decisions
    description="Routes tasks to appropriate specialists"
)

# Route a task
result = router.route_task(
    task="Analyze our system logs for security threats",
    state={}
)

print(result["routed_to"])  # "security_expert"
print(result["messages"][-1].content)
```

#### Features

- **Automatic Routing**: LLM-based agent selection
- **Manual Routing**: Explicit agent specification
- **Dynamic Registry**: Add/remove agents at runtime
- **Fallback Logic**: Defaults to first agent if routing fails

### 6. Agent Registry

```python
from arc.agents.agent_registry import AgentRegistry

# Create registry
registry = AgentRegistry(
    name="production_registry",
    registry_dir="./agent_data",
    auto_save=True
)

# Register agents
registry.register(
    agent=my_agent,
    description="Research agent with search capabilities",
    capabilities=["research", "search", "analysis"],
    tools=["search_web", "analyze_text"],
    tags=["production", "research"],
    version="1.0.0",
    metadata={"team": "research", "priority": "high"}
)

# Find agents
research_agents = registry.find_by_capability("research")
print(f"Found {len(research_agents)} research agents")

# Search agents
results = registry.search("data analysis")

# Get agent
agent = registry.get("my_agent_name")

# Track execution
import time
start = time.time()
result = agent.invoke({"messages": [("user", "query")]})
execution_time = time.time() - start

registry.record_execution(
    agent_name="my_agent_name",
    success=True,
    execution_time=execution_time
)

# Get statistics
stats = registry.get_stats("my_agent_name")
print(f"Success rate: {stats['success_rate']:.1%}")
print(f"Avg time: {stats['avg_time']:.2f}s")

# Print summary
registry.print_summary()
```

```python
# ✓ GOOD: Comprehensive error handling
@tool
def safe_database_query(sql: str) -> str:
    """Execute SQL query on database."""
    try:
        # Validate
        if not sql or not sql.strip():
            return "Error: Empty SQL query provided."

        if "DROP" in sql.upper() or "DELETE" in sql.upper():
            return "Error: Destructive operations not allowed."

        # Execute
        results = execute_sql(sql)

        if not results:
            return "Query executed successfully. No results found."

        return format_results(results)

    except SQLSyntaxError as e:
        return f"SQL Syntax Error: {str(e)}. Please check your query."

    except PermissionError as e:
        return f"Permission Error: {str(e)}. Check table access rights."

    except Exception as e:
        logger.error(f"Database error: {e}", exc_info=True)
        return f"Database Error: {str(e)}. Contact support if issue persists."
```

```python
import logging

    logger.info(f"Starting execution: {query}")
    start_time = time.time()

    try:
        result = agent.invoke({
            "messages": [("user", query)]
        })
        execution_time = time.time() - start_time

        # Record success
        registry.record_execution(
            agent_name=agent.name,
            success=True,
            execution_time=execution_time
        )

        logger.info(
            f"Execution successful: {execution_time:.2f}s"
        )
        return result

    except Exception as e:
        execution_time = time.time() - start_time

        # Record failure
        registry.record_execution(
            agent_name=agent.name,
            success=False,
            execution_time=execution_time
        )

        logger.error(
            f"Execution failed: {str(e)}",
            exc_info=True
        )
        raise

    agent=my_agent,
    query="Research quantum computing"
```

### Example 4: Production Deployment

**Complete production setup with monitoring, error handling, and optimization.**

```python
import logging
from typing import Dict, Any
from arc.agents import AgentFactory
from arc.agents.agent_registry import AgentRegistry
from arc.rl import RLManager, HeuristicRewardCalculator
from langchain_openai import ChatOpenAI
import time

# Configure logging
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
    handlers=[
        logging.FileHandler('production_agent.log'),
        logging.StreamHandler()
    ]
)
logger = logging.getLogger(__name__)

# Configuration
class AgentConfig:
    MODEL = "gpt-4o-mini"
    TEMPERATURE = 0.7
    MAX_TOKENS = 2000
    ENABLE_CACHING = True
    ENABLE_RL = True
    MAX_RETRIES = 3
    TIMEOUT = 30

# Setup RL
rl_manager = RLManager(
    tool_names=["search", "analyze", "summarize"],
    q_table_path="production_data/q_table.pkl",
    exploration_rate=0.1,  # Low for production
    use_embeddings=True
)

reward_calculator = HeuristicRewardCalculator()

# Create production agent
llm = ChatOpenAI(
    model=AgentConfig.MODEL,
    temperature=AgentConfig.TEMPERATURE,
    max_tokens=AgentConfig.MAX_TOKENS,
    request_timeout=AgentConfig.TIMEOUT
)

factory = AgentFactory(default_llm=llm)

production_agent = factory.create_react_agent(
    name="production_agent",
    tools=[search_tool, analyze_tool, summarize_tool],
    prompt="Professional production agent prompt...",
    enable_caching=AgentConfig.ENABLE_CACHING,
    cache_type="semantic",
    rl_enabled=AgentConfig.ENABLE_RL,
    rl_manager=rl_manager,
    reward_calculator=reward_calculator
)

# Setup registry
registry = AgentRegistry(name="production", auto_save=True)
registry.register(
    production_agent,
    capabilities=["research", "analysis"],
    tags=["production", "critical"]
)

# Production execution wrapper
def execute_with_retry(agent, query: str, max_retries: int = 3) -> Dict[str, Any]:
    """Execute agent with retry logic and monitoring."""

    for attempt in range(max_retries):
        start_time = time.time()

        try:
            logger.info(
                f"Executing query (attempt {attempt + 1}/{max_retries}): {query}"
            )

            result = agent.invoke({
                "messages": [("user", query)]
            })

            execution_time = time.time() - start_time

            # Validate result
            if not result.get("messages"):
                raise ValueError("Empty response from agent")

            # Record success
            registry.record_execution(
                agent_name=agent.name,
                success=True,
                execution_time=execution_time
            )

            logger.info(
                f"Query successful in {execution_time:.2f}s"
            )

            return {
                "success": True,
                "result": result,
                "execution_time": execution_time,
                "attempts": attempt + 1
            }

        except Exception as e:
            execution_time = time.time() - start_time

            logger.error(
                f"Attempt {attempt + 1} failed: {str(e)}",
                exc_info=True
            )

            # Record failure
            registry.record_execution(
                agent_name=agent.name,
                success=False,
                execution_time=execution_time
            )

            if attempt == max_retries - 1:
                # Final attempt failed
                return {
                    "success": False,
                    "error": str(e),
                    "execution_time": execution_time,
                    "attempts": max_retries
                }

            # Wait before retry
            time.sleep(2 ** attempt)  # Exponential backoff

# Health check
def health_check(agent) -> bool:
    """Check if agent is functioning properly."""
    try:
        result = agent.invoke({
            "messages": [("user", "health check")]
        })
        return bool(result.get("messages"))
    except Exception as e:
        logger.error(f"Health check failed: {e}")
        return False

# Main production loop
def main():
    logger.info("=== Production Agent Started ===")

    # Health check
    if not health_check(production_agent):
        logger.error("Health check failed! Agent not ready.")
        return

    logger.info("Health check passed ✓")

    # Example queries
    queries = [
        "Research latest AI developments",
        "Analyze market trends in tech sector",
        "Summarize findings about quantum computing"
    ]

    results = []

    for query in queries:
        result = execute_with_retry(
            production_agent,
            query,
            max_retries=AgentConfig.MAX_RETRIES
        )
        results.append(result)

        if result["success"]:
            logger.info(
                f"✓ Query successful in {result['execution_time']:.2f}s "
                f"({result['attempts']} attempts)"
            )
        else:
            logger.error(
                f"✗ Query failed after {result['attempts']} attempts: "
                f"{result['error']}"
            )

    # Print statistics
    logger.info("\n=== Execution Statistics ===")
    stats = registry.get_stats(production_agent.name)
    logger.info(f"Total executions: {stats['executions']}")
    logger.info(f"Success rate: {stats['success_rate']:.1%}")
    logger.info(f"Average time: {stats['avg_time']:.2f}s")

    # Save RL progress
    rl_manager.save_q_table()
    logger.info("RL Q-table saved")

    logger.info("=== Production Agent Finished ===")

if __name__ == "__main__":
    main()
```

## Summary

The Arc Framework provides a comprehensive suite of agent types and patterns:

### Core Agents
1. **ReactAgent**: Fundamental ReAct pattern agent for general tasks
2. **SelfConsistencyAgent**: Multiple responses with majority voting for reliability
3. **ReflexionAgent**: Self-improving agent with evaluation and reflection
4. **ReasoningDuoAgent**: Two-agent system for explicit reasoning

### Agent Management
5. **AgentFactory**: Consistent agent creation with shared configuration
6. **AgentRouter**: Dynamic routing to appropriate specialists
7. **HandoffAgent**: Coordinator agent that delegates to specialists
8. **AgentRegistry**: Enterprise-grade agent management and monitoring

### Advanced Features
- **Reinforcement Learning**: Intelligent tool selection optimization
- **Caching**: LLM response caching for performance and cost reduction
- **Multi-Agent Workflows**: Mixture of Agents and sequential pipelines
- **Persistence**: Save and load agent configurations

### Key Design Principles
- **Single Responsibility**: Each agent type has a clear purpose
- **Consistent Interface**: All agents inherit from BaseAgent
- **Extensibility**: Easy to create custom agent types
- **Production Ready**: Built-in monitoring, error handling, and optimization
