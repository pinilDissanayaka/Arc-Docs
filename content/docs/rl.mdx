# Reinforcement Learning in Arc

Complete guide to reinforcement learning capabilities in Arc Framework for intelligent tool selection and continuous improvement.

---

## Introduction

Arc includes built-in reinforcement learning capabilities that enable agents to learn from experience and continuously improve their tool selection over time. The RL system uses Q-learning with semantic state representation to generalize across similar queries.

### Why Use RL in Arc?

Traditional agent systems make the same tool selection decisions repeatedly, even when they fail. Arc's RL system learns from outcomes to:

- **Optimize Tool Selection**: Learn which tools work best for different query types
- **Reduce Costs**: Minimize unnecessary LLM calls by learning efficient tool sequences
- **Improve Over Time**: Continuously refine decision-making based on accumulated experience
- **Handle Ambiguity**: Make better choices when multiple tools could solve a task
- **Adapt to Domains**: Specialize to your specific use case and data

### When to Use RL

**Good Use Cases:**
- Agents with 5+ tools where selection is non-obvious
- Tasks with clear success/failure criteria
- Long-running agents that handle repeated query types
- Cost-sensitive applications (reduce unnecessary tool calls)
- Domains where optimal strategies aren't known upfront

**Not Recommended For:**
- Simple agents with 1-2 tools
- One-off queries with no repetition
- Tasks where correctness is critical and exploration is risky
- Real-time systems where inference speed is paramount

## Core Concepts

### Q-Learning

Arc uses Q-learning, a value-based reinforcement learning algorithm:

```
Q(s, a) = Q(s, a) + α * [r + γ * max(Q(s', a')) - Q(s, a)]
```

Where:
- `Q(s, a)` = Quality of action `a` in state `s`
- `α` = Learning rate (how fast to learn)
- `r` = Reward received
- `γ` = Discount factor (importance of future rewards)
- `s'` = Next state
- `a'` = Next action

### State-Action-Reward Cycle

```
1. Agent observes state (user query)
2. Agent selects action (tool to use)
3. Agent receives reward (success/failure)
4. Agent updates Q-value
5. Repeat
```

### Exploration vs Exploitation

- **Exploration**: Try new tools to discover better strategies
- **Exploitation**: Use known best tools based on learned Q-values
- **Balance**: Epsilon-greedy strategy balances both

## Getting Started

### Basic RL Setup

```python
from arc.agents import AgentFactory
from arc.rl import RLManager, HeuristicRewardCalculator
from langchain_core.tools import tool
from langchain_openai import ChatOpenAI

# Define tools
@tool
def search(query: str) -> str:
    """Search for information."""
    return f"Search results for: {query}"

@tool
def calculator(expression: str) -> str:
    """Calculate mathematical expression."""
    return str(eval(expression))

@tool
def database_query(query: str) -> str:
    """Query database."""
    return f"Database results for: {query}"

# Set up RL
tools = [search, calculator, database_query]
llm = ChatOpenAI(model="gpt-4o-mini")

rl_manager = RLManager(
    tool_names=[t.name for t in tools],
    q_table_path="rl_data/q_table.pkl",
    exploration_rate=0.15,
    use_embeddings=True  # Semantic state matching
)

reward_calc = HeuristicRewardCalculator()

# Create RL-enabled agent
factory = AgentFactory(default_llm=llm)
agent = factory.create_react_agent(
    name="rl_agent",
    tools=tools,
    rl_enabled=True,
    rl_manager=rl_manager,
    reward_calculator=reward_calc
)

# Agent learns which tools work best!
result = agent.invoke({"messages": [("user", "What is 15 * 23?")]})
print(result["messages"][-1].content)
```

### Quick Training Loop

```python
# Training queries
training_queries = [
    "What is 5 * 10?",
    "Search for Python documentation",
    "Calculate 100 / 4",
    "Find information about LangChain",
    "Query database for user records"
]

# Train for multiple epochs
for epoch in range(10):
    print(f"\nEpoch {epoch + 1}/10")

    for query in training_queries:
        result = agent.invoke({"messages": [("user", query)]})
        print(f"  Query: {query}")
        print(f"  Tools used: {result.get('rl_metadata', {}).get('selected_tools', [])}")

    # Reduce exploration as training progresses
    rl_manager.anneal_exploration(decay_rate=0.95)

    # Save Q-table periodically
    if (epoch + 1) % 5 == 0:
        rl_manager.save()

print(f"\nFinal exploration rate: {rl_manager.exploration_rate:.3f}")

# Check learning progress
stats = rl_manager.get_statistics()
print(f"Total states learned: {stats['total_states']}")
print(f"Average Q-value: {stats['avg_q_value']:.2f}")
```

## RLManager API

### Initialization

```python
from arc.rl import RLManager, ExplorationStrategy

rl_manager = RLManager(
    tool_names: List[str],                    # Available tool names
    q_table_path: Optional[str] = None,       # Path to save/load Q-table
    exploration_rate: float = 0.15,           # Exploration probability (epsilon)
    learning_rate: float = 0.1,               # Learning rate (alpha)
    discount_factor: float = 0.99,            # Discount factor (gamma)
    exploration_decay: float = 0.995,         # Decay rate for exploration
    min_exploration_rate: float = 0.01,       # Minimum exploration rate
    use_embeddings: bool = True,              # Use semantic state matching
    embedding_model: str = "all-MiniLM-L6-v2", # Embedding model name
    similarity_threshold: float = 0.7,        # Similarity threshold for state matching
    exploration_strategy: ExplorationStrategy = ExplorationStrategy.EPSILON_GREEDY
)
```

## State Representation

### Discrete States (use_embeddings=False)

Direct string matching of queries.

```python
rl_manager = RLManager(
    tool_names=tool_names,
    use_embeddings=False  # Discrete state representation
)

# Each unique query becomes a separate state
# "calculate 5+3" != "calculate 5 + 3"
# Fast lookup, no embedding overhead
# Limited generalization
```

**Pros:**
- Fast state lookup
- No embedding computation
- Exact state matching

**Cons:**
- No generalization to similar queries
- Large state space for varied queries
- Requires exact query repetition

**Best for:**
- Fixed set of queries
- Exact query repetition
- Low-dimensional state spaces

### Semantic States (use_embeddings=True)

Queries encoded as embeddings for semantic similarity.

```python
rl_manager = RLManager(
    tool_names=tool_names,
    use_embeddings=True,           # Semantic state representation
    embedding_model="all-MiniLM-L6-v2",
    similarity_threshold=0.85      # How similar states must be to match
)

# Similar queries map to similar states:
# "calculate 5+3" ≈ "compute 5 plus 3"
# Better generalization to novel inputs
# Slightly higher computational cost
```

**Pros:**
- Generalizes to similar queries
- Handles paraphrasing
- Smaller effective state space
- Better transfer learning

**Cons:**
- Embedding computation overhead
- Requires embedding model
- Approximate matching

**Best for:**
- Varied query phrasings
- Generalization to new queries
- Natural language inputs
- Production systems

### State Similarity Matching

```python
# Configure similarity threshold
rl_manager = RLManager(
    tool_names=tool_names,
    use_embeddings=True,
    similarity_threshold=0.85  # 0.0 to 1.0
)

# Higher threshold = more exact matching
# Lower threshold = more generalization

# Example similarity scores:
# "calculate 5+3" vs "compute 5 plus 3" → 0.92 (match)
# "calculate 5+3" vs "search for cats" → 0.12 (no match)
```

## Exploration Strategies

### Epsilon-Greedy (Default)

Explore with probability ε, exploit otherwise.

```python
rl_manager = RLManager(
    tool_names=tool_names,
    exploration_rate=0.15,  # 15% exploration
    exploration_strategy=ExplorationStrategy.EPSILON_GREEDY
)

# With probability ε: select random action
# With probability 1-ε: select best action (max Q-value)

# Gradually reduce exploration
for episode in range(num_episodes):
    result = agent.invoke(state)

    if episode % 10 == 0:
        rl_manager.anneal_exploration(decay_rate=0.95)
```

**Best for:**
- General purpose
- Balanced exploration
- Simple implementation

### Epsilon Decay

Automatic exploration annealing.

```python
rl_manager = RLManager(
    tool_names=tool_names,
    exploration_rate=0.3,        # Start high
    exploration_decay=0.995,     # Decay per episode
    min_exploration_rate=0.01,   # Minimum floor
    exploration_strategy=ExplorationStrategy.EPSILON_DECAY
)

# Exploration automatically decreases over time
# No manual annealing needed
```

**Best for:**
- Long training runs
- Automatic annealing
- Set-and-forget training

### Upper Confidence Bound (UCB)

Systematic exploration based on uncertainty.

```python
rl_manager = RLManager(
    tool_names=tool_names,
    exploration_strategy=ExplorationStrategy.UCB,
    ucb_c=2.0  # Exploration parameter (higher = more exploration)
)

# UCB formula: Q(s,a) + c * sqrt(ln(N(s)) / N(s,a))
# Balances:
# - Tools with high Q-values (exploitation)
# - Tools tried less often (exploration)
```

**Best for:**
- Systematic exploration
- Fewer tools (< 10)
- Bandit-like problems

### Thompson Sampling

Bayesian approach with uncertainty quantification.

```python
rl_manager = RLManager(
    tool_names=tool_names,
    exploration_strategy=ExplorationStrategy.THOMPSON_SAMPLING
)

# Samples from belief distributions over Q-values
# More sophisticated than epsilon-greedy
# Better theoretical guarantees
```

**Best for:**
- Bayesian approach
- Uncertainty quantification
- Research applications

## Training Workflows

### Basic Training Loop

```python
from arc.rl import RLManager, HeuristicRewardCalculator

# Setup
rl_manager = RLManager(
    tool_names=[t.name for t in tools],
    q_table_path="rl_data/q_table.pkl",
    exploration_rate=0.3,  # Start with high exploration
    use_embeddings=True
)

reward_calc = HeuristicRewardCalculator()

agent = factory.create_react_agent(
    name="learning_agent",
    tools=tools,
    rl_enabled=True,
    rl_manager=rl_manager,
    reward_calculator=reward_calc
)

# Training loop
training_queries = [
    "What is 5 * 10?",
    "Search for Python documentation",
    "Calculate 100 / 4",
    "Find information about LangChain"
]

for epoch in range(10):
    print(f"Epoch {epoch + 1}/10")

    for query in training_queries:
        result = agent.invoke({"messages": [("user", query)]})
        print(f"  Query: {query}")
        print(f"  Tools: {result.get('rl_metadata', {}).get('selected_tools', [])}")

    # Reduce exploration
    rl_manager.anneal_exploration(decay_rate=0.95)

    # Save periodically
    if (epoch + 1) % 5 == 0:
        rl_manager.save()

print(f"Final exploration rate: {rl_manager.exploration_rate}")
```

### Curriculum Learning

Gradually increase task difficulty.

```python

    "Search for cats"

    "What is the square root of 144?",
    "Search for Python asyncio documentation"

    for query in medium_queries:
        agent.invoke({"messages": [("user", query)]})
    rl_manager.anneal_exploration(0.95)

# Phase 3: Complex multi-step
complex_queries = [
    "Calculate the compound interest on $1000 at 5% for 10 years",
    "Search for latest research on quantum computing and summarize"
]

for epoch in range(10):
    for query in complex_queries:
        agent.invoke({"messages": [("user", query)]})
```

```python
# Define valid action function
def get_valid_actions(query: str) -> List[str]:
    """Determine which tools are valid for this query."""
    if "calculate" in query.lower():
        return ["calculator"]
    elif "search" in query.lower():
        return ["search", "database_query"]

        return ["search", "calculator", "database_query"]
```

### Error Handling

```python
from arc.exceptions import RLError, EmbeddingError

def safe_rl_invoke(agent, state):
    """Invoke with RL error handling."""

    try:
        result = agent.invoke(state)
        return result

    except EmbeddingError as e:
        # Embedding failed, fall back to discrete states
        logger.error(f"Embedding error: {e}")
        rl_manager.use_embeddings = False
        result = agent.invoke(state)
        rl_manager.use_embeddings = True
        return result

    except RLError as e:
        # RL failed, disable RL for this request
        logger.error(f"RL error: {e}")
        agent.rl_enabled = False
        result = agent.invoke(state)
        agent.rl_enabled = True
        return result
```
